QA Pipeline con IA

Genera casos de prueba con un LLM, pero valida cada selector contra el DOM real antes de ejecutar nada.

Ver repo en GitHub →

El problema

Un LLM puede alucinar un selector que no existe en la página. Sin validarlo antes de ejecutar, el resultado es un timeout confuso de Playwright — no queda claro si falló la app o si el test estaba mal escrito de entrada.

Este pipeline separa esos dos problemas en capas explícitas: primero valida que el JSON generado tenga la forma correcta, después valida que los selectores existan en el DOM real, y recién ahí ejecuta.

Decisiones de diseño

  • Sin agente autónomo de navegador — la validación explícita antes de ejecutar es el diferencial.
  • Playwright "pelado" en todo el runner, sin mezclar con el framework de tests.
  • La decisión de "esto amerita alerta en Slack" vive en n8n, no en el código.
  • results.json plano y append-only — sin base de datos, a propósito.
